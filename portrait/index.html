세로 고정 · 실험용

이 방향 그대로,
원격 데스크톱으로.

설치한 앱을 열면 원격 데스크톱으로 자동 이동합니다.
연결 후에도 세로 방향이 유지되는지 테스트합니다.

실행 상태 확인 중방향 확인 중

1. 앱 설치

앱 이름과 아이콘은 공식 PWA와 같습니다. 이 설치 페이지는 세로 고정용입니다.

설치 후 홈 화면의 원격 데스크톱 아이콘을 열면 바로 연결 사이트로 이동합니다.

2. 고정하고 연결

설치된 앱에는 세로 고정이 기본 적용됩니다. 원격 연결 후 휴대폰을 돌려 보세요.

테스트 결과를 알려 주세요.
연결 전에는 고정되지만 연결 후 다시 회전한다면, Chrome이 외부 사이트로 이동하면서 고정을 유지하지 않는 경우일 수 있습니다. 전체 화면 고정 후 연결도 한 번 비교해 보세요.

Google 공식 앱이 아닌 개인 테스트용 연결 앱입니다.
Google 사이트의 콘텐츠나 로그인 정보를 중계하지 않습니다.

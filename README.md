# 원격 데스크톱 PWA 방향 고정

Chrome 원격 데스크톱을 세로 또는 가로 방향으로 실행하는 개인용 PWA 시작 페이지입니다. Google 공식 앱이 아닙니다.

## 설치

GitHub Pages에서 세로 또는 가로 고정을 선택한 뒤 Chrome의 앱 설치 기능을 사용합니다. 설치된 앱을 열면 Google 공식 원격 데스크톱 사이트로 자동 이동합니다. Google 스토어 앱이 대신 열리면 해당 앱의 지원되는 링크 열기를 해제하세요.

앱 이름은 한국어 공식 PWA 기준 Chrome 원격 데스크톱 / 원격 데스크톱입니다. 두 방향 앱은 같은 이름과 공식 아이콘을 사용합니다. 설치 화면에서 방향을 구분하세요.

## 호스팅

main 브랜치 루트에서 GitHub Pages를 배포합니다. 정적 HTML, CSS, JS와 이미지로 구성되며 외부 빌드 도구가 필요하지 않습니다. 모든 로컬 경로는 GitHub Pages의 저장소 하위 경로와 호환됩니다.

Google 로그인과 원격 연결은 Google 사이트에서 직접 처리하며 이 페이지는 로그인 정보를 받거나 중계하지 않습니다. 아이콘은 Google 공식 PWA가 사용하는 gstatic 이미지입니다.

## 문제 해결

설치된 앱에서 초기 화면을 유지하려면 방향별 URL에 ?setup=1 을 붙이세요. 브라우저에서 설치 페이지를 방문하면 자동 이동하지 않습니다.

방향 고정의 외부 사이트 이동 후 유지 여부는 브라우저 및 기기 동작에 의존하며 모든 기기에서 보장되지 않습니다. GitHub Pages 호스팅도 영구 가용성을 보장하는 서비스는 아닙니다.
